# سلة جو (SallaJo) — Frontend

![SallaJo screenshot](https://raw.githubusercontent.com/Amro-Aladghem/SallaJo-Frontend/main/my-app/public/sall-Jo.png)

A concise, recruiter-focused summary of the SallaJo frontend — a user-facing e‑commerce web application built to connect customers with sellers.

Why this project matters

- Clear business goal: a marketplace storefront and seller portal that enables online shopping, product management, and order handling.
- User-centered features that improve conversion and seller productivity.
- Demonstrates production-ready frontend skills with TypeScript and modern tooling.

Key features (what SallaJo provides)

- Customer experience
  - Branded storefront and product browsing (responsive layouts and mobile navigation).
  - Product listing and product detail screens with clear visual hierarchy.
  - Seamless user flows guarded by authenticated routes when needed (login-protected pages).
  - Friendly error and not-found handling to keep users on track.

- Seller experience
  - Dedicated seller views and layouts for managing products and orders.
  - Seller-specific navigation and screens to streamline day-to-day operations.

- Admin & platform
  - Separate admin views and routing structure to manage the platform and content.

Technical highlights (short)

- Frontend: React + TypeScript
- Tooling: Vite for fast builds and dev server
- Organized by views, components, contexts, and services (clear separation of concerns)
- Production-ready static assets and branding included (logo and screenshots)
